# CHEQUE Desktop

تطبيق مكتبي محلي على Windows لإدارة الشيكات والتحصيل الفعلي للخزينة وتصنيف المبالغ حسب المرقين العقاريين والتجميد والتحويلات.

## المعمارية
- Tauri 2 + Rust
- React + TypeScript + Vite
- SQLite محلية في مجلد بيانات التطبيق
- واجهة عربية RTL
- تخزين المبالغ كأعداد صحيحة بالسنتيم (100 سنتيم = 1 دج)

## قواعد العمل
1. تسجيل الشيك لا يتطلب تحديد المرقي.
2. تسجيل الإيداع لا يزيد رصيد الخزينة.
3. لا يصنف المبلغ إلا بعد تأكيد دخوله فعلياً من قيد دائن في كشف حساب الخزينة.
4. يمكن تأكيد القيد البنكي على دفعات، ولا يتجاوز مجموع التحصيلات قيمته الدائنة.
5. يمكن ربط التحصيل بأكثر من شيك وربط الشيك بتحصيلات متعددة مع حفظ المصدر.
6. كامل المبلغ المحصل والمصنف مستحق للمرقي.
7. التجميد لا يغير رصيد الخزينة.
8. إعداد التحويل لا يخصم الرصيد؛ التنفيذ الفعلي فقط ينشئ حركة خارجة.
9. يمنع تجاوز مبلغ التحصيل أو التخصيص أو الحجز أو السيولة.
10. لا تحذف الحركات المالية؛ التصحيح بقيود عكسية موثقة.

## ما تم تنفيذه في هذه الدفعة
- شاشة تسجيل الشيكات وعرضها دون طلب المرقي.
- تسجيل الإيداع الكلي أو الجزئي دون اعتباره تحصيلاً.
- إدخال قيود كشف الحساب الدائنة والمدينة.
- تأكيد التحصيل كلياً أو جزئياً من القيد الدائن.
- مطابقة التحصيل مع عدة شيكات مع حماية حدود المبالغ المودعة.
- تسجيل حركة الخزينة الداخلة تلقائياً عند تأكيد التحصيل فقط.
- سجل عرض التحصيلات المؤكدة والقيود البنكية.

## التطوير على Windows
يتطلب Node.js 20+ وRust toolchain وتهيئة Tauri 2.

```powershell
npm install
npm run tauri dev
```

## اختبارات قاعدة البيانات
```powershell
python scripts/test_schema.py
python scripts/test_workflow.py
```

## الحالة
البرنامج ما زال قيد التطوير. لم تكتمل بعد وحدات التصنيف وقوائم المرقين والتجميد والتحويلات والتصدير، كما لم يُبنَ Windows Installer بعد. لا تدخل بيانات تشغيل حقيقية قبل إكمال اختبارات البناء والتشغيل والنسخ الاحتياطي على جهاز Windows المستهدف.
