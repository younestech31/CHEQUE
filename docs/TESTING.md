# اختبارات المشروع

## اختبارات قاعدة البيانات
شغّل الأوامر التالية من جذر المشروع:

```powershell
python scripts/test_schema.py
python scripts/test_workflow.py
```

الاختبارات تعمل على SQLite مؤقتة في الذاكرة ولا تمس قاعدة البيانات التشغيلية. يطبق اختبار سير العمل الترحيلات 1 و2 و3 مرة واحدة كما يفعل مشغل الترحيلات.

## ما تغطيه الاختبارات
- حدود قيد التحصيل البنكي ومجموع التخصيصات.
- حدود التجميد وسجل حركة التحويل المنفذ.
- منع تكرار الشيكات وقيود كشف الحساب.
- منع تجاوز مجموع الإيداعات للقيمة الاسمية للشيك.
- منع تجاوز التحصيلات للقيد الدائن.
- منع استخدام القيد المدين كتحصيل.
- حدود مطابقة الشيكات بالمبالغ المودعة والتحصيلات.
- توزيع التحصيل الواحد على عدة أسطر.
- منع ربط مشروع بمرقٍ آخر.
- منع تعديل أو حذف أسطر التصنيف المالية.
- التحقق من ترحيلات قاعدة البيانات.

## فحوصات البناء
اختبارات SQLite شُغلت محلياً على نسخة مطابقة لمخطط المستودع، واجتازت اختبارات التحصيل والتصنيف والتجميد الأساسية. لم يكتمل بناء Rust/Tauri أو TypeScript/Vite في بيئة التنفيذ هذه لعدم توفر Rust/Cargo وتعذر تنزيل اعتماديات npm. يجب تنفيذ `npm run build` و`npm run tauri build` على جهاز Windows المستهدف قبل إدخال بيانات حقيقية.
