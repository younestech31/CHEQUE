# القرارات المعمارية

- Windows، جهاز واحد، تشغيل محلي دون خادم.
- Tauri 2 + React + TypeScript + Rust + SQLite.
- واجهة عربية RTL قريبة من Excel.
- الشيكات تسجل دون تحديد مرقٍ.
- التحصيل البنكي والتصنيف والتجميد والحجز والتنفيذ مراحل منفصلة.
- كامل المبلغ المحصل والمصنف مستحق للمرقي.
- التجميد على مستوى سطر التخصيص، جزئياً أو كلياً.
- التحويل المحضر لا يخصم من الخزينة.
- دعم ربط عدة شيكات بتحصيل وتقسيم التحصيل على عدة زبائن.
- المبالغ تحفظ بالسنتيم كأعداد صحيحة.
