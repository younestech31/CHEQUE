# CHEQUE Desktop

تطبيق مكتبي محلي على Windows لإدارة الشيكات والتحصيل الفعلي للخزينة وتصنيف المبالغ حسب المرقين والتجميد والتحويلات.

## المعمارية
- Tauri 2 + Rust
- React + TypeScript + Vite
- SQLite محلية
- تخزين المبالغ كأعداد صحيحة بالسنتيم (100 سنتيم = 1 دج)

## قواعد العمل
1. تسجيل الشيك لا يتطلب تحديد المرقي.
2. لا يصنف المبلغ إلا بعد تأكيد دخوله فعلياً من كشف حساب الخزينة.
3. كامل المبلغ المحصل والمصنف مستحق للمرقي.
4. التجميد لا يغير رصيد الخزينة.
5. إعداد التحويل لا يخصم الرصيد؛ التنفيذ الفعلي فقط ينشئ حركة خارجة.
6. يمنع تجاوز مبلغ التحصيل أو التخصيص أو الحجز أو السيولة.
7. لا تحذف الحركات المالية؛ التصحيح بقيود عكسية موثقة.

## التطوير
يتطلب Node.js 20+ وRust toolchain وتهيئة Tauri 2 على Windows.

```powershell
npm install
npm run tauri dev
```

## الحالة
العمل جارٍ. الواجهة الأولية ومخطط البيانات وقواعد الحماية واختبارات SQLite قيد التأسيس. لا تستخدم بيانات تشغيل حقيقية قبل اكتمال خدمات العمليات واختبارات التطبيق المكتبي.
